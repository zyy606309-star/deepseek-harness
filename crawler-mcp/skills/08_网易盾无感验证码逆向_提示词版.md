# 🧩 网易盾无感验证码逆向提示词版

> 面向 Claude / GPT 的直接投喂模板。配合 `07_网易盾无感验证码逆向_执行版.md` 使用，目标是限制单轮任务边界，减少无效分析和 token 消耗。

> 模板只约束输出范围，不替模型补事实。任何变量名、接口名、常量和版本结论都必须来自已给证据；证据不足时输出“证据不足”。

---

## 一、文档定位

本文档负责：

- 给 Claude / GPT 的单轮提示词模板
- 限制每轮只解决一个问题
- 统一输出格式
- 在长会话中做摘要压缩和纠偏

本文档不负责：

- 讲解网易盾原理
- 规定完整阶段策略
- 替代执行版做阶段判断

配套文件：

- 原理版：`06_网易盾无感验证码逆向_原理版.md`
- 执行版：`07_网易盾无感验证码逆向_执行版.md`

推荐使用顺序：

1. 先用执行版确定当前处于哪个阶段
2. 再从本文档复制对应模板
3. 每轮结束后用摘要压缩模板收口

---

## 二、使用规则

每次只复制一个模板，不要把多个阶段混在一轮里。

使用前先补全这些字段：

- 页面 URL
- 触发选择器
- 当前阶段摘要
- 本轮问题对应的最小片段
- 证据来源和时间
- 当前 SDK/浏览器版本

固定要求：

- 只让模型解决一个问题
- 限制输出格式
- 不要让模型复述原文
- 不要同时问“定位 + 修复 + 原理解释”
- 不要把单个成功样本当成跨版本规则

## 十四、推荐搭配

推荐这样组合使用：

1. 用 `07_网易盾无感验证码逆向_执行版.md` 控制整体阶段
2. 用本文档选择当前阶段的单轮提示词
3. 每轮结束后用“摘要压缩模板”收口
4. 进入下一轮时只带阶段摘要，不带旧长文

这样做的目的不是减少分析质量，而是把分析质量集中在真正需要的证据上。
