# 失败回退

## 页面阶段

- Hook 没命中：
  先确认触发动作，再扩一档范围；仍无结果就停，别直接猜本地环境。
- 首屏初始化错过：
  回到页面入口，优先 preload 或更早期注入。
- 断点不稳：
  回退 Hook 路线，不要在不稳定断点上硬磨。

## 本地复现阶段

- 本地直接崩：
  先看代理 env log，再看 `first divergence`，不要先全局补对象。
- 连续多轮无推进：
  回浏览器补证据，而不是继续脑补。
- 补一个坏一片：
  回滚最近补丁，缩小到更小的因果单元。

## 深挖阶段

- 去混淆后行为漂移：
  回滚最近一轮变换，缩小改写面。
- VMP 插桩数据过大：
  只保留 opcode、pc/ip、栈顶摘要和输出摘要。
